# Clipper Privacy Policy

Clipper is a personal automation tool used only by its owner to upload videos to the owner's own YouTube channels and Instagram accounts. It is not a public service and does not collect data from any other person.

## What the app accesses
- It requests the YouTube scope `https://www.googleapis.com/auth/youtube.upload`, which only allows uploading videos to the channel the owner selects at sign-in.
- It cannot read, edit or delete existing videos, and it cannot read account or analytics data.

## How data is used and stored
- The OAuth refresh token is stored only in a local file on the owner's own computer and server. It is used solely to upload the owner's videos.
- No Google user data is collected, sold, shared, transferred to third parties, or used for advertising.
- Clipper's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access
Access can be revoked at any time at https://myaccount.google.com/permissions, and the stored token file can be deleted.
